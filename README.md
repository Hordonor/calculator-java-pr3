# Калькулятор — практична робота 3

Консольний Maven-застосунок виконує додавання, віднімання, множення та ділення двох чисел типу `double`. Передбачено обробку ділення на нуль і власне checked-виключення `InvalidInputException` для некоректних даних. Додатковий метод квадратного кореня демонструє перевірку невід’ємного аргументу.

## Запуск у Windows

Потрібна Java 17 або новіша. `run.bat` перемикає консоль на UTF-8, запускає тести й після успішної перевірки запускає калькулятор.

```powershell
cd C:\Users\panca\Desktop\dz\java3
chcp 65001
[Console]::OutputEncoding = [System.Text.UTF8Encoding]::new()
$OutputEncoding = [Console]::OutputEncoding
.\run.bat
```

Окремі команди:

```powershell
chcp 65001
.\mvnw.cmd clean test
.\mvnw.cmd exec:java
```

## Приклад

```text
Введіть перше число: 12
Введіть друге число: 4
Введіть операцію (+, -, *, /): /
Результат: 12.0 / 4.0 = 3.0
Обробку запиту завершено.
```

## Класи

- `Calculator` — арифметичні методи, валідація скінченності чисел, обробка ділення на нуль і маршрутизація операцій.
- `InvalidInputException` — власне перевірене виключення для некоректних параметрів і введення.
- `Main` — консольна взаємодія; `try-catch-finally` показує зрозумілі помилки та повідомлення про завершення кожного запиту.
- `CalculatorTest` і `MainTest` — тести операцій, винятків і розбору введення.
